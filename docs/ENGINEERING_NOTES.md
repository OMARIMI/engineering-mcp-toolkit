# Engineering MCP Toolkit Notes

This resource provides fixed project context for the Engineering MCP Toolkit.

## Approved capabilities

- Calculate current with Ohm's law.
- Calculate power from voltage and current.
- Search the approved local component dataset.
- Save draft notes only inside the project `drafts/` folder.
- Generate a structured comparison prompt for two components.

## Dataset

The approved dataset is `data/components.json` with 121 component records.

## Safety reminder

The only write-capable tool is `save_draft_note`, and it is restricted to creating new markdown or text files inside `drafts/`.
